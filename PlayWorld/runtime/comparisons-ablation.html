GC002 · Rectangular Sculpture Orbit

Geometry Consistency Preset Only vs. Preset + Agent
OBJECTIVE

Trace a rectangular trajectory around the central full-body sculpture while maintaining the camera’s original orientation, then return to the starting position.

Preset Only executes the fixed rectangular trajectory in front of the central sculpture, so the sculpture remains continuously visible in the foreground. WorldPlay Agent (Preset + Agent) adapts the trajectory online to move around the sculpture, causing it to leave and later re-enter the field of view—providing a genuine test of spatial memory rather than keeping the target in view.

PRESET ONLY (FIXED ACTION) hold(D,1950ms) → hold(W,7800ms) → hold(A,3900ms) → hold(S,7800ms) → hold(D,1950ms)
WORLDPLAY AGENT (PRESET + AGENT) hold(D,1950ms) → hold(W,7800ms) → hold(A,3900ms) → hold(A,600ms) [Agent Extend] → hold(S,7800ms) → hold(D,1950ms)
